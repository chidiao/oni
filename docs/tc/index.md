## 冷却液

- 石油只适合冷却高温液体，比热容低，费电
- 花蜜是综合性能最好的冷却液，温度范围广，比热容高

| 液体       | 冰点 (°C) | 沸点 (°C) | 比热容 (DTU/g)/°C |
| :--------- | :-------- | :-------- | :---------------- |
| 水         | -0.65     | 99.35     | 4.179             |
| 盐水       | -7.5      | 99.7      | 4.100             |
| 浓盐水     | -22.5     | 102.75    | 3.400             |
| 污染水     | -20.65    | 119.35    | 4.179             |
| 污染浓盐水 | -25.50    | 106.75    | 3.6               |
| 花蜜♥      | -82.5     | 160       | 4.100             |
| 原油       | -40.1     | 399.9     | 1.690             |
| 石油       | -57.1     | 538.9     | 1.760             |
