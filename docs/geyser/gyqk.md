# 高压气库

## 高压气库

- 铺的液体量不能超过 2kg（超压阈值）

![](/imgs/gyqk/qiku1.jpg)

## 气库封存

- 气库拆迁后减小占地面积
- 1kg 石脑油 + 粘蛋白
- 砖块先拆上后拆下

![](/imgs/gyqk/fengcun1.jpg)

## 高压制氧

- 上氧下氢更加稳定，出气口（左一）会和相邻格子进行气体合并

![](/imgs/gyqk/zhiyang1.jpg)

- 电解器被四格液体覆盖，质量不触发淹没即可，1 kg 足以
- 电解器只会判定气压，所以液体不会导致过压

![](/imgs/gyqk/zhiyang2.jpg)
