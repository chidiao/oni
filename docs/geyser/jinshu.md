# 金属火山

[大叔](https://www.yuque.com/u25332524/ftq4u7/lslsuy)

- 蒸汽控制在每格 50kg - 100kg
- 发热量大的可以增加蒸汽量，但是不能超过 150kg，超压

| 火山类型       | 蒸汽机数量 | 灌水量           |
| :------------- | :--------- | :--------------- |
| 金、钨火山     | 1 台       | 1000 千克水      |
| 铁、铜、钴火山 | 1~2 台     | 2000 千克水      |
| 铝火山         | 2~3 台     | 2000~3000 千克水 |
