# 高压液库

## 高压液库

- 砖块会高压损坏，闸门不会
- 需要一格气体来创建高压液库

![](/imgs/gyyk/chuye2.jpg)

- 朴实无华版
- 18 x 11（含梯子）
- 无自动化，直接带气封闭，不用刻意构建和保持
- 抽干了也能再次形成

![](/imgs/gyyk/chuye1.jpg)
