# 原油裂化

## 手动版本

![](/imgs/geyser/yuanyou1.jpg)

### 火成岩热量吸收

![](/imgs/geyser/yuanyou2.jpg)

- 上层轨道用隔热砖封闭
- 如果液体表层液体量较少，发生高温热交换时，容易直接裂解，破坏真空环境
- 轨道只在液体深处热交换更加安全

![](/imgs/geyser/yuanyou3.jpg)

### 热量回收

- 灌注原油时，热量进行回收
- 给石油降温的同时，给自己进行升温

![](/imgs/geyser/yuanyou4.jpg)

- 石油烧好后，关闭气闸，给蒸气室再回收一部分热量
- 该步骤效率低，可在闲时操作，或者跳过

![](/imgs/geyser/yuanyou5.jpg)
