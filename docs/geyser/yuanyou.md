- 油井可以浸泡，方便换热
- 油井不怕过热，但是输入的水怕高温相变

## 金属火山裂化

### 数据

- 熔融金属在蒸气室会迅速凝固成碎片，也就是初始温度为熔点
- 金属碎片从熔点开始慢速降温，并装载轨道，所以熔点高能搬运的热量才高

| 火山类型   | 比热容    | 喷发温度 | 熔点     |
| :--------- | :-------- | :------- | :------- |
| **铁火山** | **0.449** | 2526.85° | 1534.85° |
| **钴火山** | **0.420** | 2226.85° | 1494.85° |
| **铜火山** | **0.386** | 2226.85° | 1083.85° |
| **铌火山** | **0.265** | 3226.85° | 2476.85° |
| **铝火山** | **0.910** | 1726.85° | 660.25°  |
| **钨火山** | **0.134** | 3726.85° | 3421.85° |
| **金火山** | **0.129** | 2626.85° | 1063.85° |

### 实测

| 火山类型   | 平均温度     | 低峰温度       | 方案适配性                       |
| :--------- | :----------- | -------------- | :------------------------------- |
| **铁火山** | 800° - 1000° | 300° 极少/个别 | **最佳。** 熔点高，热量大        |
| **钴火山** |              |                | **优秀。** 熔点高，热量大        |
| **铜火山** |              |                | **良好。** 稍逊一些              |
| **铌火山** | 400° - 500°  | 300° 一般/不少 | 勉强。滴液降温太快，等同于熔点低 |
| **铝火山** |              |                | **有缺陷。** 熔点太低            |
| **钨火山** | 200° +       |                | **不适用。** 副作用              |
| **金火山** |              |                | **不适合。** 热量太少            |

## 原油裂化

### 强制相变

- 原油条件
  - 大于 5千克，每次相变消耗 5千克
  - 原油温度小于沸点 3°
- 热源条件
  - 热源温度高于原油沸点 3°
  - 必须是实体方格或建筑
  - 轨道上的碎片不算

### 蓝图

- 蒸气室
- 高温火成岩运往烧油室
- 轨道循环榨取中温火成岩热量
- 低温火成岩再走一遍蒸汽机液冷池子

![](/imgs/geyser/yuanyou9.jpg)

- 烧油室
- 加热时，顶部轨道用隔热门格挡
- 防止高温火成岩直接和顶部石油接触，容易直接裂解
- 即使发生裂解，封闭房间，液体满格，也可清理掉酸气

![](/imgs/geyser/yuanyou8.jpg)

- 冷却室
- 两条输油管道进行一定的换热

![](/imgs/geyser/yuanyou1.jpg)

- 底部蒸气室持续消耗热量

![](/imgs/geyser/yuanyou2.jpg)
