# 原油开发

## 油井开采

- 油井可以浸泡，方便换热
- 油井不怕过热，但是输入的水怕高温相变
- 所以需要控一下温度

![](/imgs/geyser/youjing1.jpg)

## 原油裂化

- 蒸气室
- 高温火成岩运往烧油室
- 轨道循环榨取中温火成岩热量
- 低温火成岩再走一遍蒸汽机液冷池子

![](/imgs/geyser/yuanyou9.jpg)

- 烧油室
- 加热时，顶部轨道用隔热门格挡
- 防止高温火成岩直接和顶部石油接触，容易直接裂解
- 即使发生裂解，封闭房间，液体满格，也可清理掉酸气

![](/imgs/geyser/yuanyou8.jpg)

- 冷却室
- 两条输油管道进行一定的换热

![](/imgs/geyser/yuanyou1.jpg)

- 底部蒸气室持续消耗热量

![](/imgs/geyser/yuanyou2.jpg)
