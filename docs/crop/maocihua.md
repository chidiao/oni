# 毛刺花

| 名字     | 毛刺花               |
| :------- | :------------------- |
| 平均产量 | 267 千卡/周期        |
| 温度     | 5 - 30°C             |
| 环境     | 氧气/污染氧/二氧化碳 |
| 气压     | 150 克 - 10 千克     |
| 光照     | 最低 200 勒克斯      |
| 灌溉     | 水 20 千克/周期      |

## 蘑菇浆果

- 18 x 11
- 超压二氧化碳环境
- 菌泥运输不要过水
- 虽然菌泥走自动化，但是并不会完全禁止小人手动施肥，只能降低概率
- 左上角清扫覆盖不全（施肥），拟芽
