# 农场

- 需要灌溉的都需要液冷控温
- 不需要灌溉的通常萝卜就够了

## 火椒水草

- 18 x 11
- 这两个作物都是高温，比较契合 40 - 50°
- 先把金属砖里的各种线路铺好再建液培砖，否则只能拆顶部隔热砖进行返修
