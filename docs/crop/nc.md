# 农场

## 控温

- 需要灌溉的都需要液冷控温
- 不需要灌溉的通常萝卜就够了
- 后期主要依赖高温泉水
- 源头控温（常温灌溉），费电
- 环境控温（高温灌溉），费电，作物吃水的时候，温差的热量会直接被吞掉，相当于节省了一部分电力

## 小麦花蜜

- 18 x 11
- 灌溉管道要用隔热管，防止爆管
- 小麦只有一格高度
- 种了一棵糖心树，前期需要压低温度，树枝长大后，温度回调
- 制冰机经常导致结块，需要改进

## 蘑菇浆果

- 18 x 11
- 超压二氧化碳环境
- 菌泥运输不要过水
- 虽然菌泥走自动化，但是并不会完全禁止小人手动施肥，只能降低概率
- 左上角清扫覆盖不全（施肥），拟芽

![](/imgs/crop/mogu1.jpg)

## 火椒水草

- 18 x 11
- 直接灌溉高温水版本
- 运输一把梭

![](/imgs/crop/huojiaoshuicao4.jpg)

- 管道循环
- 外挂控温

![](/imgs/crop/huojiaoshuicao5.jpg)

- 旧版本-常温水控温版
- 顶部三层结构，管道线路不好维护
- 后期水来源主要依靠高温泉水
