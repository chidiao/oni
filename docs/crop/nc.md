# 农场

## 控温

- 需要灌溉的都需要液冷控温
- 不需要灌溉的通常萝卜就够了
- 后期主要依赖高温泉水
- 源头控温（常温灌溉），费电
- 环境控温（高温灌溉），费电，作物吃水的时候，温差的热量会直接被吞掉，相当于节省了一部分电力
