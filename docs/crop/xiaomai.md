# 冰霜小麦

| 名字     | 冰霜小麦               |
| :------- | :--------------------- |
| 平均产量 | 1 单位/周期            |
| 温度     | -55 - 5°C              |
| 环境     | 氧气/污染氧/二氧化碳   |
| 气压     | 150 克 - 10 千克       |
| 光照     | 不限                   |
| 灌溉     | 水 20 千克/周期        |
| 施肥     | 泥土 5 千克/周期       |

## 小麦花蜜

- 18 x 11
- 灌溉管道要用隔热管，防止爆管
- 小麦只有一格高度
- 种了一棵糖心树，前期需要压低温度，树枝长大后，温度回调
- 制冰机经常导致结块，需要改进
