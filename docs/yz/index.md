## 幸福度

### 来源

| 来源                 | 幸福度变化          | 备注                         |
| :------------------- | :------------------ | :--------------------------- |
| 梳理站               | **+5**              | 需要养殖员操作，同时降低野性 |
| 小动物直饮器（咸乳） | **+5**              | 持续 1 周期                  |
| 小动物直饮器（墨汁） | **+3**              | 持续 1 周期                  |
| 小动物公寓（陆生）   | **+1**              | 获得“舒适”状态，持续 1 周期  |
| 水中城堡（水生）     | **+1**              | 获得“舒适”状态，持续 1 周期  |
| 即将饿死             | **-10**             | 卡路里耗尽时触发             |
| 拥挤                 | **-1 / 每超出一只** | 动物数量超出房间容量时触发   |
| 体温不适             | **-1**              | 环境温度过冷或过热           |
| 温顺（已驯化）       | **-1**              | 驯化状态自带的基础惩罚       |

| 幸福度等级 | 幸福度数值 | 代谢速率     | 繁殖速率                       |

| **满足**   | 0 ~ 3      | 默认（100%） | 默认（基础速率）               |
| **快乐**   | ≥ 4        | 默认（100%） | 基础速率 × (1 + 2.25 × 幸福度) |

## 尖块兽

- 尖块兽只能吃到2格高的果实。
- 漫殖藤左右各12个果实。长果实的前提必须有可蔓延的空格，例如：主体贴墙无法向墙的(上)方向蔓延。

- 该气动门布局刚好可以让漫殖藤长满24格。
- 上方刚好铺设清扫器，同时注意房间系统。
