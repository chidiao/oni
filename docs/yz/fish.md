# 养鱼

## 基本数据

### 水域

| 液体名称   | 满格质量 (千克) | 可游动质量 (千克) |
| :--------- | :-------------- | :---------------- |
| 水         | 1000            | 350               |
| 盐水       | 1100            | 385               |
| 浓盐水     | 1200            | 420               |
| 污染浓盐水 | 1200            | 420               |

- 低于游动质量，挣扎
- 满足游动质量，才会有机会获得拥挤
- 拥挤只看联通水域大小，不看可游动水域大小

### 养殖

| 鱼类       | 食物   | 进食量 / 作物产量 | 养殖比例 |
| :--------- | :----- | :---------------- | :------- |
| **帕库鱼** | 海梳蕨 | 20千克 / 10千克   | 1 : 2    |
| **灯喙鱼** | 藤壶星 | 13% / 25%         | 2 : 1    |
| **彩斑鱿** | 管虫   | 25% / 12.5%       | 1 : 2    |

### 其他

- 捕鱼陷阱底格需要被淹没（单格液体质量35%）
- 捕鱼陷阱升级为移取点
- 注意水底液体质量须满足污染土超压条件
- 种子溢出，海梳蕨优先级降低

## 帕库鱼（通用）

- 18 x 6
- 补充模块用的鱼类移取点
- 房间建造及滴液从下往上进行，一旦封顶会很麻烦

![](/imgs/yz-pky1.jpg)

- 用一个砖块格挡，让清扫器不能覆盖底层装载器，避免循环运蛋
- 如果砖上落了蛋，清扫不到！

![](/imgs/yz-pky2.jpg)

- 三个清扫器分别运送 食物、杂物、蛋

![](/imgs/yz-pky4.jpg)

- 这里水量低，不能游动，鱼儿卡的很整齐

![](/imgs/yz-pky3.jpg)

## 彩斑鱿

- 18 x 6
- 铺少量液体，并且右侧留空，鱼儿就不会过去产蛋了，清扫器更灵活（通用）

![](/imgs/yz-cby1.jpg)

- 该房间太拥挤，左侧清扫器（所有+蛋）运到右边，再由右侧清扫器分拣（所有）
