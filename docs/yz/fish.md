# 养鱼

## 基本数据

### 水域房间

| 液体名称   | 满格质量 (千克) | 可游动质量 (千克) |
| :--------- | :-------------- | :---------------- |
| 水         | 1000            | 350               |
| 盐水       | 1100            | 385               |
| 浓盐水     | 1200            | 420               |
| 污染浓盐水 | 1200            | 420               |

- 低于游动质量，挣扎，不会出现拥挤
- 满足游动质量，会出现拥挤
- 拥挤只看联通水域大小，不看可游动水域大小
- 可以中层铺多液体，上下层铺少量液体，但是必须达到挥发物超压条件

### 养殖比例

| 鱼类       | 食物   | 进食量 / 作物产量 | 养殖比例 |
| :--------- | :----- | :---------------- | :------- |
| **帕库鱼** | 海梳蕨 | 20千克 / 10千克   | 1 : 2    |
| **灯喙鱼** | 藤壶星 | 13% / 25%         | 2 : 1    |
| **彩斑鱿** | 管虫   | 25% / 12.5%       | 1 : 2    |
| **海马**   | 巨钳蚌 |                   | 2 : 1    |

### 补充

- 鱼类移取点用来补充小动物数量
- 左侧水量少一点，不能游动，把鱼儿卡到右侧
- 左侧水太少的话，会被挥发物破坏结构（注意）

![](/imgs/yz/fish-buchong.jpg)

### 清扫

- 用一个砖块格挡，让清扫器不能覆盖底层装载器，避免循环运蛋
- 如果砖上落了蛋，清扫不到！问题很严重！
- 参考鱿鱼模式

![](/imgs/yz/pakuyu2.jpg)

- 三个清扫器分别运送 食物、杂物、蛋

![](/imgs/yz/pakuyu4.jpg)
