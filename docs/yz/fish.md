# 养鱼

## 基本数据

### 水域房间

| 液体名称   | 满格质量 (千克) | 可游动质量 (千克) |
| :--------- | :-------------- | :---------------- |
| 水         | 1000            | 350               |
| 盐水       | 1100            | 385               |
| 浓盐水     | 1200            | 420               |
| 污染浓盐水 | 1200            | 420               |

- 低于游动质量，挣扎，不会出现拥挤
- 满足游动质量，会出现拥挤
- 拥挤只看联通水域大小，不看可游动水域大小
- 可以中层铺多液体，上下层铺少量液体，但是必须达到挥发物超压条件
