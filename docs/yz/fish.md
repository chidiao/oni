# 养鱼

## 基本数据

#### 帕库鱼

海梳蕨：20% / 周期

帕库鱼：40% / 周期

#### 灯喙鱼

海梳蕨：25% / 周期

灯喙鱼：13% / 周期

#### 简易养鱼模块

- 捕鱼陷阱底格需要被淹没（单格液体质量35%）
- 捕鱼陷阱升级为移取点
- 注意水底液体质量须满足污染土超压条件
- 种子溢出，海梳蕨优先级降低

## 养鱼模块

- 18 x 6
- 补充模块用的鱼类移取点
- 房间建造及滴液从下往上进行，一旦封顶会很麻烦

- 用一个砖块格挡，让清扫器不能覆盖底层装载器，避免循环运蛋
- 三个清扫器分别运送 食物、杂物、蛋
