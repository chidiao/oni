# 飞鱼

- 喷浮飞鱼 只会下 贵族飞鱼蛋
- 贵族飞鱼 只会下 喷浮飞鱼蛋
- 喷浮飞鱼 + 贵族飞鱼 会下 后壳飞鱼和洁净飞鱼蛋
- 后壳飞鱼 + 贵族飞鱼 会下 后壳飞鱼蛋
- 洁净飞鱼 + 贵族飞鱼 会下 洁净飞鱼蛋
- 非贵族飞鱼 都只会下 贵族飞鱼蛋

::: tip

普通飞鱼产量 95%

贵族飞鱼产量只有 10%

慎养贵族飞鱼，只用来育种

:::

## 飞鱼养殖

- 18 x 11
- 贵族飞鱼精养一只，育种就行
- 贵族飞鱼每周期投喂0.1周期，活着就行
- 对应的蛋运输到对应的房间

![](/imgs/yz-fy1.jpg)

- 左侧清扫器不可以覆盖滑槽
  - 前期喷浮飞鱼可以下喷浮飞鱼蛋
  - 方案一：保留覆盖，并且手动熬过这一阶段
  - 方案二：完全不覆盖滑槽，把喷浮飞鱼蛋运到贵族房，再运回来
