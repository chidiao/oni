# Skills Reference

技能参考

触发：技能参考、文档规范、写作规范

This directory contains reference standards for documenting this project.

## Overview Page Rules

总览页规则

触发：总览页、分类首页、标题、英文标签

- Big title (h1) — 分类名称
- English tag below: inline code like `` `Crops` ``, `` `Farming` ``, `` `Geysers` ``, `` `Guide` ``, `` `Building` ``, `` `Temperature Control` ``
- Directory listing: bullet list of sub-doc links (no subheading required)
- Other content follows as needed

## Index Pages

索引页规则

触发：索引页、index.md、子文档、链接列表

All category overview pages (index.md) must follow:
1. `# 分类名`
2. `` `EnglishTag` ``
3. Bullet list of sub-documents (no level-2 heading like "目录" or "子文档")
4. Additional content (tables/descriptions) as needed

## Total Count

首页卡片数量

触发：首页、features、卡片、数量、满行

- 8/9 feature cards on home, full rows when possible
- Prioritize big categories first

## Navigation

导航

触发：nav、顶部导航、分组、菜单

- `docs/.vitepress/menu.ts` 只配置 nav 分组：建造 / 间歇泉 / 种植 / 养殖
- nav 为扁平链接，不展示二级下拉菜单：每组直接链接到该分类总览页（由 `menu.ts` 分组的 `link` 提供）
- 分类子项只在 sidebar 分组中展示；总览页也可由 sidebar 指南组 / 首页 / links 进入
- 「指南」不在 menu/nav 中，只在 `sidebar.ts` 里配置
- "其他" 不进 nav，只在 sidebar 显示

## Sidebar Rules

侧边栏规则

触发：sidebar、侧边栏、分组、路径

- Sidebar is path-scoped via an object in `docs/.vitepress/sidebar.ts`
- Always-visible common group: 指南 + 其他
- 指南 group in sidebar = 总览 + 各分类总览入口（建造/间歇泉/种植/养殖）
- Order is always: 指南 → 动态分组 → 其他
- Grouping:
  - 建造 → `/build/`
  - 间歇泉 → `/geyser/`
  - 种植 / 养殖 → `/crop/`, `/farm/`
  - 养殖按 `menu.ts` item 的 `tag` 拆成陆生/水生两组：`tag: '水生'` 归水生养殖，其余（含缺失）归陆生养殖
  - 其他页面（`/guide/`, `/skills/`）只显示 指南 + 其他
- 参考链接页位于 `/guide/links`，由「其他」组进入

## Image Archiving

图片归档

触发：图片归档、未引用图片、图片页、/guide/images、迁移、删除

- 本规则只作用于「未被引用的图片」和 `/guide/images` 展示页，不影响其他文档及其图片
- 归档分两种方式，**默认「不迁移」**：
  1. **归档并迁移**：未被引用的图片（包括子目录中的）移到 `imgs/` 根目录，并由 `/guide/images` 展示
  2. **归档不迁移**（默认）：未被引用的图片直接删除，不迁移到 `imgs/` 根目录
- 不迁移时，同步清理 `/guide/images` 中指向已删除图片的条目及其小标题
- 迁移后的未引用图片由 `/guide/images` 展示（`logo.png` 除外）
- 展示页小标题用中文，不带扩展名、不带序号
- 同一组仅序号不同的图片（如 `guandao1.jpg`、`guandao2.jpg`）共用一个中文小标题
- 死链清理：当图片被其他文档引用（通常已移入子目录）或文件已不存在时，从 `/guide/images` 删除该图片引用及其小标题

## Naming Optimization

命名优化

触发：命名优化、图片命名、重命名、序号、缺省序号、补序号

- 目前只针对图片命名
- 适用于带序号的同组图片（如 `xx1.jpg`、`xx2.jpg`、`xx3.jpg`）
- 序号以 `0` 开头的（如 `xx01.jpg`）也要改为非 `0` 开头（如 `xx1.jpg`）
- `0` 开头的图片按大序号处理，不参考其自身序号大小：去零后若与同组非 `0` 开头图片序号冲突，改用组内的大序号（如 `xx7.jpg`、`xx8.jpg`）
- 若用户指定了目录，只优化该目录内的图片
- 文档更新中删除了某张图（如 `xx2.jpg`）导致序号出现空缺时，用后续图片重命名填补缺省序号，保持序号连续
- 重命名遵循**最小改动量**：用同组最后一张（如 `xx5.jpg`）改名为缺省的 `xx2.jpg`，而不是把 `xx3`、`xx4`、`xx5` 依次前移；每次只改动一个文件
- 重命名后，同步更新所有文档中对该图片的引用

## Data Lookup

资料查询 / 资料补充

触发：资料查询、资料补充、查资料、查数据、补数据、补充资料、wiki

- 触发后，按当前文档主题（如「毛刺花」）联网查询相关资料与数据
- 来源优先级：wiki 为最高优先级；wiki 无相关资料时先告知用户，再参考其他可信网站
- 查询结果以表格形式插入当前文档，表格首列/首行统一用「名字」作为标题
- 支持一次查询多个目标（如毛刺花 + 冰霜小麦），放入同一表格
- 表格方向按「属性数量」决定：
  - 属性较少：横向，表头为 `名字 + 各属性名`，每个目标一行（`名字` 列填目标名）
  - 属性较多：纵向，表头为 `名字 + 各目标名`，每个属性一行（`名字` 列填属性名）

### 作物字段规则

查询作物时，按以下表格取用字段：

| 字段     | 是否必填 | 说明                                   |
| :------- | :------- | :------------------------------------- |
| 名字     | 必填     | 作物名称                               |
| 平均产量 | 必填     | 格式 `xx / 周期`，由收获量折算为每周期 |
| 温度     | 必填     | 生长温度                               |
| 环境     | 按需     | 气体环境                               |
| 气压     | 按需     | 生长所需气压范围                       |
| 光照     | 按需     | 最低光照要求                           |
| 灌溉     | 按需     | 灌溉物质与消耗量                       |
| 施肥     | 按需     | 施肥物质与消耗量                       |
| 成熟时间 | 不需要   | 时间类字段，已折算进平均产量           |
| 挂留时间 | 不需要   | 时间类字段                             |
| 成长时间 | 不需要   | 时间类字段                             |
| 收获耗时 | 不需要   | 时间类字段                             |
| 尺寸     | 不需要   | 非人工种植所需数据                     |
| 淹没致死 | 不需要   | 致死类信息，非人工种植所需数据         |

### 动物字段规则

查询动物时，按以下表格取用字段：

| 字段     | 是否必填 | 说明                                   |
| :------- | :------- | :------------------------------------- |
| 名字     | 必填     | 动物名称                               |
| 温度     | 必填     | 舒适温度范围                           |
| 空间     | 必填     | 需求空间                               |
| 食物     | 必填     | 食物种类                               |
| 消耗量   | 按需     | 食物消耗量                             |
| 产物     | 按需     | 具体产物名称与产量                     |
| 转化率   | 按需     | 消耗产出比，只写百分比，如 `95%`       |
| 比例     | 按需     | 养殖配比                               |
| 变异条件 | 选填     | 简单明了的变异触发条件                 |
| 孵化期   | 不需要   | 周期类字段                             |
| 成熟期   | 不需要   | 周期类字段                             |
| 产卵周期 | 不需要   | 周期类字段                             |
| 寿命     | 不需要   | 生命周期字段                           |
| 代谢     | 不需要   | 每周期代谢                             |

- 字段顺序：食物 → 消耗量 → 产物（具体产物名）→ 转化率 → 掉落物（具体名称）
- 产物与掉落物的区分：持续转化的产出归为产物；一次性掉落（死亡、蜕壳等）归为掉落物
- 多个产物时，每个产物及其转化率紧邻排列
- 转化率只写百分比，不写消耗与产出的绝对数值
- 掉落物不使用笼统的「死亡掉落」字段，按具体名称拆成独立字段（如「蟹肉」「蟹壳」），放在转化率之后
- 变异条件只填变种自身的触发条件（如 `20 - 60°`），基础类型留 `-`；不写触发结果，像飞鱼那样随时间递增/递减的复杂机制不列入表格
