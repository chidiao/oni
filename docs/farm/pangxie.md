# 抛壳蟹

## 属性

| 名字     | 抛壳蟹         | 沙泥蟹               | 木壳蟹                           |
| :------- | :------------- | :------------------- | :------------------------------- |
| 温度     | 0 - 40°        | 0 - 40°              | 0 - 40°                          |
| 空间     | 12 格          | 12 格                | 12 格                            |
| 食物     | 污染土/腐烂物  | 污染土/腐烂物/菌泥   | 污染土/腐烂物/菌泥               |
| 消耗量   | 70 千克/周期   | 15 千克/周期         | 70 千克/周期                     |
| 沙子     | +35 千克/周期  | +10 千克/周期        | +17.5 千克/周期                  |
| 转化率   | 50%            | 66.7%                | 25%                              |
| 蟹肉     | 1200 千卡      | 4000 千卡            | 1200 千卡                        |
| 蟹壳     | 60 千克        | -                    | 500 千克                         |
| 变异条件 | -              | 水                   | 乙醇                             |
| 特性     | 壳可粉碎为石灰 | 清除周围环境中的病菌 | 生活在乙醇中，木蟹壳可粉碎为木材 |

- 巨钳蚌消耗沙子 35 千克/周期
- 共生比例（巨钳蚌 : 蟹）
  - 抛壳蟹 1 : 1
  - 沙泥蟹 1 : 3.5
  - 木壳蟹 1 : 2
