# 飞鱼

## 飞鱼属性

| 名称     | 温度     | 空间  | 食物             | 消耗产出比（千克/周期） |
| :------- | :------- | :---- | :--------------- | :---------------------- |
| 喷浮飞鱼 | 15 - 55° | 16 格 | 污染氧           | 50/47.5/95%             |
| 贵族飞鱼 | 20 - 40° | 16 格 | 污染氧/氧气/氯气 | 30/3/10%                |
| 洁净飞鱼 | 0 - 60°  | 16 格 | 氯气             | 30/28.5/95%             |
| 厚壳飞鱼 | 0 - 60°  | 16 格 | 氧气             | 50/47.5/95%             |

## 变异机制

| 名称     | 无贵族飞鱼                    | 临近贵族飞鱼                  |
| :------- | :---------------------------- | :---------------------------- |
| 喷浮飞鱼 | 贵族飞鱼↑ 喷浮飞鱼↓           | 厚壳/洁净飞鱼↑ 喷浮飞鱼↓      |
| 贵族飞鱼 | 喷浮飞鱼                      | 喷浮飞鱼                      |
| 洁净飞鱼 | 贵族飞鱼↑ 喷浮飞鱼↓ 洁净飞鱼↓ | 洁净飞鱼↑ 贵族飞鱼↓ 喷浮飞鱼↓ |
| 厚壳飞鱼 | 贵族飞鱼↑ 喷浮飞鱼↓ 厚壳飞鱼↓ | 厚壳飞鱼↑ 贵族飞鱼↓ 喷浮飞鱼↓ |
