# 飞鱼

## 变异机制

- 贵族飞鱼只生贵族飞鱼蛋
- 喷浮飞鱼大概率生贵族飞鱼蛋，小概率生喷浮飞鱼蛋
- 喷浮飞鱼临近贵族飞鱼，提升概率生厚壳飞鱼和洁净飞鱼蛋
- 厚壳飞鱼和洁净飞鱼大概率生贵族飞鱼蛋，小概率生喷浮飞鱼蛋
- 厚壳飞鱼和洁净飞鱼临近贵族飞鱼，提升概率生自己对应的蛋
- 贵族飞鱼产量极低，只有育种价值，没有转化价值

## 飞鱼养殖

- 18 x 11
- 凑活用模块
- 喷口贴钻石变温版，液体气体换热太慢

![](/imgs/farm/feiyu1.jpg)

- 左侧投放清洁飞鱼，转化氯气
- 右侧投放喷浮和贵族，育种
  - 厚壳全部溺死
- 右侧投放清洁和贵族，育种
  - 喷浮和厚壳全部溺死
- 杂物运出去尽量不破坏水门

![](/imgs/farm/feiyu2.jpg)

- 间歇泉休眠期间，投喂廉价氧气，保一只贵族就行
- 飞鱼有概率在投放格直接产蛋，不被清扫器投放，导致孵化位置错误，手动调整
