# 树鼠

## 属性

| 名字     | 树鼠          | 毛绒树鼠      | 树鼠鱼                   |
| :------- | :------------ | :------------ | :----------------------- |
| 温度     | 10 - 40°      | 10 - 40°      | 10 - 40°                 |
| 空间     | 12 格         | 4 格          | 12 格                    |
| 食物     | 植物/鱼子酱   | 植物/鱼子酱   | 鱼子酱/壳                |
| 消耗量   | 生长进度/食物 | 生长进度/食物 | 壳 20 千克/鱼子酱 1 千克 |
| 泥土     | +20 千克/次   | +12.5 千克/次 | -                        |
| 壳灰岩   | -             | -             | +20 千克/周期            |
| 肉       | 1 千克        | 1 千克        | -                        |
| 鱼片     | -             | -             | 2 千克                   |
| 变异条件 | -             | 顶针芦苇      | 鱼子酱                   |

- 树鼠与毛绒树鼠会播种；毛绒树鼠还会拥抱蛋和复制人
- 树鼠鱼为水生变种，可在液体环境中播种
- 共生比例（按进食消耗的生长进度计算，1 只所需人工植株数）：
  - 树鼠：乔木树 0.08 株；粘胶棕榈 0.4 株
  - 毛绒树鼠：乔木树 0.1 株；粘胶棕榈 0.5 株
