# 鱼类

## 通用

### 水域房间

| 液体名称   | 满格质量 (千克) | 可游动质量 (千克) |
| :--------- | :-------------- | :---------------- |
| 水         | 1000            | 350               |
| 盐水       | 1100            | 385               |
| 浓盐水     | 1200            | 420               |
| 污染浓盐水 | 1200            | 420               |

- 低于游动质量，挣扎，不会出现拥挤
- 满足游动质量，会出现拥挤
- 拥挤只看联通水域大小，不看可游动水域大小
- 可以中层铺多液体，上下层铺少量液体，但是必须达到挥发物超压条件

### 补充区

- 运输 + 清扫 固定位置搭配

![](/imgs/fish/buchong1.jpg)

- 两种气体占位置，防止液体推过来
- 两格液体占位置，防止液体推过来
- 一格可游动，超不超压无所谓，一格不可游动，把小动物锁在一格

## 灯喙鱼

| 名称   | 消耗产出       | 温度     | 比例 |
| ------ | -------------- | -------- | ---- |
| 灯喙鱼 | 12.5% 生长进度 | 0 - 60°  | 2    |
| 藤壶星 | 25% 生长进度   | 25 - 45° | 1    |

- 18 x 6

![](/imgs/fish/denghuiyu4.jpg)

- 吸氧气，幸福度 +2
- 确保每层只有一种液体，可以避免液体低落合并推开等问题
- 确保氧气格下方可游动
