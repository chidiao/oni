# 养鱼

## 通用

### 水域房间

| 液体名称   | 满格质量 (千克) | 可游动质量 (千克) |
| :--------- | :-------------- | :---------------- |
| 水         | 1000            | 350               |
| 盐水       | 1100            | 385               |
| 浓盐水     | 1200            | 420               |
| 污染浓盐水 | 1200            | 420               |

- 低于游动质量，挣扎，不会出现拥挤
- 满足游动质量，会出现拥挤
- 拥挤只看联通水域大小，不看可游动水域大小
- 可以中层铺多液体，上下层铺少量液体，但是必须达到挥发物超压条件

### 补充区

- 运输 + 清扫 固定位置搭配

![](/imgs/fish/buchong1.jpg)

- 两种气体占位置，防止液体推过来
- 两格液体占位置，防止液体推过来
- 一格可游动，超不超压无所谓，一格不可游动，把小动物锁在一格

## 彩斑鱿

| 名称   | 消耗产出       | 温度      | 比例 |
| ------ | -------------- | --------- | ---- |
| 彩斑鱿 | 25% 生长进度   | 40 - 100° | 1    |
| 管虫   | 12.5% 生长进度 | 50 - 110° | 2    |
| 针胆团 |                | 40 - 80°  |      |

- 18 x 11
- 一只鱿鱼的墨汁可以喂 10 只小动物
- 照料 + 挤奶 + 公寓，可精养 2.5 只鱿鱼
- 挤奶 + 公寓，可养 3 只鱿鱼（纯挤墨汁，繁殖补充可能跟不上）
- 照料 + 挤奶，可精养 4 只鱿鱼
- 针胆团，浸泡液体不包含水
- 储物箱：精炼碳 + 硫

![](/imgs/fish/youyu1.jpg)

- 灌溉高温水版本，需要液冷控温（外挂，公寓易过热）

![](/imgs/fish/youyu2.jpg)

- 18 x 11
- 加热版，精养 3 只
- 液体加热器 - `5 x 5` 范围内需要至少一格液体达到 `400千克` 以上

![](/imgs/fish/caibanyou1.jpg)

## 海马

| 名称   | 珍珠          | 温度     | 比例 |
| ------ | ------------- | -------- | ---- |
| 海马   | -3125 克/周期 | 0 - 60°  | 2    |
| 巨钳蚌 | +6300 克/周期 | 25 - 45° | 1    |

- 18 x 11
- 精养4+只，8格拥挤
- 产出 菌泥、粘蛋白、鱼子酱、珍珠
- 储物箱 - 沙子

![](/imgs/fish/haima1.jpg)

- 补充区
  - 只能放一层液体，防止小海马游上去
  - 左边 100克 ，右边 450千克
- 挤奶站 - 补充区数量少时禁用
