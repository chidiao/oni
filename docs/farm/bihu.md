# 壁虎

## 属性

| 名字     | 毛鳞壁虎                    | 滑鳞壁虎                           |
| :------- | :-------------------------- | :--------------------------------- |
| 温度     | 10 - 60°                    | 20 - 50°                           |
| 空间     | 12 格                       | 12 格                              |
| 食物     | 火椒藤/香脂百合/米虱木      | 米虱木/毛刺花                      |
| 消耗量   | 9.4%/6.2%/25% 生长进度      | 33.3%/16.7% 生长进度               |
| 磷矿     | +10 千克/次                 | +9 千克/次                         |
| 芦苇纤维 | 2/次（氢气环境累计 8 周期） | -                                  |
| 塑料     | -                           | 150 千克/次（氢气环境累计 3 周期） |
| 肉       | 2 千克                      | 2 千克                             |
| 变异条件 | -                           | 米虱木                             |

## 蓝图

- 18 x 11
- 一株米虱木刚好养一只壁虎

![](/imgs/farm/bihu1.jpg)

- 杂物和食物可以分开运送，也可以一起运送
- 磷矿储备一箱，多余运出，放中心供两颗萝卜使用
- 中心两列装载器可被两侧同时覆盖

![](/imgs/farm/bihu2.jpg)

- 单向门开 1.9 周期，关 0.1 周期
- 萝卜可加一个缓冲门
